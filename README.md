# Stopwatch App

A responsive and modern stopwatch web application built using HTML, CSS, and JavaScript.  
This stopwatch lets users start, pause, reset, and record laps — perfect for timing activities or tracking performance.

## Features

- Start — Begin timing instantly  
- Pause — Pause without resetting the timer  
- Reset — Clear the current timer and lap records  
  Lap — Record multiple lap times while the stopwatch is running  
- Responsive design — Works smoothly on desktop and mobile  
- Simple and elegant UI — Clean layout with intuitive controls  

## 🛠️ Technologies Used

- HTML5 – Structure and layout  
- CSS3 – Styling and responsiveness  
- JavaScript (ES6) – Stopwatch logic and interactivity  

##  How to Use

1. Click Start to begin the timer  
2. Click Lap to record a lap time  
3. Click Pause to temporarily stop  
4. Click Reset to clear the timer and laps
